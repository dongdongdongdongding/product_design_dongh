규칙
- 셀 안의 `|`는 쓰지 않는다(열이 밀린다). 굵게(`**`)와 코드(`` ` ``)는 빌드 때 벗겨진다.
- 기능 ID 범위는 `RISK-04~07`처럼 쓴다. 화면설계서의 `{EX-07}` 토큰은 ex 표의 ID로 툴팁을 만든다.
- 12.2의 화면 ID는 플로우 맵 `SCREENS`의 id와 같아야 한다(최종 검증이 시안 글자와 대조한다).
- 13.3의 화면 칸은 `D1 대시보드`처럼 화면 ID로 시작한다(SB 링크가 걸린다). 기존 화면은 메뉴 코드(`M10`)로 써도 된다.

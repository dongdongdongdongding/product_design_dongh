# build_kit.py(build_flowmap.parse)가 읽는 표

머리행 첫 셀부터 이 문자열로 시작하는 **첫 번째 표**를 읽는다. 열 순서를 바꾸지 않는다. 머리행은 아래 "다른 언어" 표의 English · 中文 · 日本語 머리행도 된다(공백 · 대소문자 무시). 장은 번호(`## 13.`, `### 12.6`, `### 13.4`, `### 6.x`)로 찾으므로 제목은 어느 언어든 된다.

| 문서 | 표 머리행 시작 | 열 | DOCDATA 키 |
|---|---|---|---|
| 기능정의서 | `### 6.x <그룹명>` 아래 `\| ID \|` | ID · 기능 · 구현 · 완료 기준 | features (group = 절 제목) |
| 기능정의서 | `\| 원본 \| 요구 항목 \|` | 원본 · 요구 항목 · 기능 ID · 이번 처리 | rtm |

| WBS | `\| ID \| 리스크 \|` | ID · 리스크 · 대응 | risks |

규칙
- 셀 안의 `|`는 쓰지 않는다(열이 밀린다). 굵게(`**`)와 코드(`` ` ``)는 빌드 때 벗겨진다.
- 기능 ID 범위는 `RISK-04~07`처럼 쓴다. 화면설계서의 `{EX-07}` 토큰은 ex 표의 ID로 툴팁을 만든다.
- 12.2의 화면 ID는 플로우 맵 `SCREENS`의 id와 같아야 한다(최종 검증이 시안 글자와 대조한다).
- 13.3의 화면 칸은 `D1 대시보드`처럼 화면 ID로 시작한다(SB 링크가 걸린다). 기존 화면은 메뉴 코드(`M10`)로 써도 된다.

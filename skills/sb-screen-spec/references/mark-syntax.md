# sb-pages.js 문법

## 화면 페이지

```js
pg({ kind: 'scr', scr: 'S1', title: '시설 관리 · 목록과 이용 조건', path: '시설 관리 > 수정',
     tag: 'old' | 'new', tagT: 'M22 확장',          // 머리줄 오른쪽 배지
     common: true,                                   // 공통 화면 요소 페이지일 때만
     purpose: '…',                                   // 없으면 SCREENS의 purpose
     marks: [ mk(번호, 위치, 제목, [설명 줄…], 옵션), … ],
     subs: [ { n: '9-1', cap: '저장 성공', html: TST('저장했습니다.') }, … ],
     mx: [ 판정표… ],                                // 화면 아래에 판정표를 붙일 때
     ctx: [ ['쓰는 데이터', '{저장} facilities[id]'], ['읽는 곳', 'P2 · D1'] ] });
```

### mk(번호, 위치, 제목, 설명, 옵션)

위치 `q`:
| 쓰기 | 찾는 것 |
|---|---|
| `'저장'` | 그 글자를 포함하는 가장 작은 요소 |
| `'^카드 제목'` | 그 글자를 가진 요소가 들어 있는 카드(`.c` · `.modal`) 전체 |
| `'$.tabsx'` | CSS 선택자 (`$.ct > :nth-child(2)`, `$.row > .c:last-child table`) |

옵션: `up: n` 부모로 n단계 · `sib: n` 다음 형제 n개까지 묶음 · `cl: '선택자'` 가장 가까운 조상 · `at: 'tl'|'tr'|'bl'|'br'` 번호 원 첫 후보 위치(실제 위치는 엔진이 글자 · 다른 원을 피해 고른다).
뒤 화면이 깔린 팝업(`.dimmed`)의 요소는 찾지 않는다.

### 설명 줄

- 보통 줄은 글머리표, `'- '`로 시작하면 2단, `'[예외]'`처럼 대괄호만 있으면 소제목.
- `"문구"`는 화면 문구로 강조된다.
- 토큰: `{저장}` 브라우저 저장 · `{서버}` 서버 · DB · `{기존}` 기존 유지 · `{조건부}` · `{EX-07}` 예외(툴팁에 상황 · 처리) · `{→P2}` 그 화면 페이지 · `{→SB-07}` 쪽 번호 · `{→#map}` 페이지 id(`map` · `verify` · 화면ID).
- 제목에 "지도"가 들어간 마커에는 지도 기준 페이지 링크가 자동으로 붙는다.

### 하위 상태 견본

`SW(제목, 본문html, ['~취소', '!삭제', '확인'])` 확인 대화상자(`~` 보조, `!` 위험) · `FX(라벨, 값, { req, err, ph, m: '문구', mc: 'err'|'wrn' })` 입력 필드 상태 · `TST(문구)` 저장 알림. `n: '9-1'`은 9번 마커에 붙는다.

## 판정표 페이지

```js
pg({ kind: 'mx', scr: 'R1', title: '위험 분석 · 강우 입력 판정표', path: '위험 분석 > 예외 처리', purpose: '…',
     mx: [ { n: '1', t: '강우 입력 조합', cols: ['구분', '선택', '값 형식', '버튼', '결과 · 문구'],
             rows: [ ['정상', '01', '정상', '활성', '결과 표시'], ['예외', '-', '공백', '비활성', '"값을 입력하세요." (EX-06)'] ],
             note: '…' } ] });
```
`O` · `X` · `-` 칸은 자동으로 모양이 바뀐다.

## SBCONF

| 키 | 뜻 |
|---|---|
| `cover` | `{ badge, titleHTML, intro, sources[], history[[버전, 날짜, 내용]] }` |
| `ref` | `() => html` 참고 설계서 분석 페이지 (없으면 기본 작성 기준) |
| `menus` | `[[메뉴코드, 메뉴명, 이번 변경, 화면들, 'new'|'old']]`, `menuNote` |
| `journeys` | `[{ t, nodes: [{id, s, k?} | {e}] }]` 업무 흐름 사슬 |
| `dict` | `{ rows: [[분류, 값, 뜻, 정하는 곳, 보이는 곳]], msgs: [[상황, 문구, 근거]] }` |
| `swatches` | `{ 기호 이름: '<svg 안쪽>' }` 지도 기호 견본 (없으면 자동) · `mapIntro` · `mapNote` |
| `screenAlias` | 문서의 메뉴 코드 → 화면 ID (`{ M10: 'M2' }`) |
| `crossFeatures` | 화면 없는 공통 기능 `{ 'COM-06': '설명' }` |
| `fieldAliases` · `fieldPass` | 12.2 필드명과 화면 라벨이 다를 때 · 화면 글자로 확인 못 하는 필드 통과 규칙 |
| `forbidden` · `forbiddenExempt` | 화면에 남으면 안 되는 표기 정규식 (false면 검사 안 함) · 예외 화면 |
| `instructions` | `() => [[사용자 지시, 반영 위치 · 근거]]` — 최종 검증 3번 표 |
| `openItems` | 남은 확인 사항 |

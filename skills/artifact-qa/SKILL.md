# 검수와 최종 검증

〔7/7 검수 · 전달〕 끝나면 `progress.md` 7단계를 체크하고, 결과 링크 · 파일과 남은 확인 사항(가정 목록)을 함께 보고한다. 브라우저 도구가 없으면 `check_docs.py` · 빌드 숫자로 대신하고 그렇게 했다고 말한다.

눈으로 한 화면씩 보는 대신 스크립트로 전부 재고, 남은 것만 눈으로 본다. 결과를 사용자에게 말할 때는 숫자(몇 건 → 0건)와 남긴 것의 이유를 함께 말한다.

## 준비

```bash
python -I scripts/check_docs.py --docs <docs> --screens D1,...      # 문서 정합
python -I scripts/build_kit.py <프로젝트 폴더>                        # 빌드
python -m http.server 8768 --bind 127.0.0.1    (프로젝트 폴더의 부모에서, 백그라운드)
```
Chrome 도구로 `http://127.0.0.1:8768/<프로젝트>/flowmap.html`을 연다. 끝나면 서버를 끄고 탭을 닫는다.

## 실행 (javascript_tool, 스크립트 앞에 `await`)

1. `scripts/audits/flowmap-sb.js` — 화면설계서 전 페이지 점검 + 최종 검증 결과 + 시안 라벨 수집(fmLabels).
2. `scripts/audits/flowmap-routes.js` — 우회 연결선이 화면을 가로지르는지.
3. 디자인 캔버스: `templates/design/harness.html`을 디자인 폴더에 두고 같은 서버로 연 뒤 `scripts/audits/design-canvas.js`(BOARDS 목록을 프로젝트에 맞게). 1번을 같은 출처에서 먼저 돌려야 플로우 맵 대비 누락을 비교한다.

화면 좌표로 클릭해 확인할 때: 스크린샷 좌표 = CSS 좌표 × (스크린샷 너비 / innerWidth).

## 결과 읽기와 고치는 방향

| 결과 | 보통 원인 | 고치는 곳 |
|---|---|---|
| 대상 없음 | 시안 문구 · 구조가 바뀜 | sb-pages.js 마커 `q` |
| 대상이 잘림 · 다른 요소가 덮음 | 표 · 카드가 넘쳐 옆 카드 밑에 깔림 | 시안 레이아웃(카드 너비, 줄바꿈 허용) |
| 원이 글자를 가림 · 원끼리 겹침 | 자동 배치가 피할 곳이 없음 | 마커 `at`, 묶음 범위(`up`/`sib`) |
| 영역끼리 겹침 · 화면 내용 넘침 · 보드 밖 잘림 | 내용이 900/940 높이를 넘음 | 높이 줄이기(지도 · 간격 · 표 tight) |
| 지도 높이 불일치 | dc-import에 높이 100% 없음 | `style="display:block;width:100%;height:100%"` |
| 하단 빈 공간 · 카드 안 빈 공간 | 행이 남는 높이를 안 채움 · 목록이 짧음 | 행 `flex:1`. 지도 옆 목록 열의 아래 여백은 내용을 지어내 채우지 말고 그대로 두고 보고 |
| 플로우 맵 대비 없음 | 시안과 캔버스 내용이 다름 | 둘을 맞춤 |
| 연결선 화면 관통 | 엔진 문제 | engine/ (드묾) |

## 최종 검증 페이지가 보는 것

원본 요구 → 기능 ID 연결, 기능이 화면에 배치됨(공통 기능은 crossFeatures), 12.2 입력 필드가 시안 글자에 있음, 예외가 검수에 연결됨, 13.3 지도가 시안에 있음, 금지 표기 없음, WBS 합계, 작업 지시 반영표, 남은 확인 사항. "확인 필요"가 0개가 될 때까지 고친다. 단 **기능 ID 연결은 충분조건이 아니다** — 요구 항목의 입력 · 동작이 실제 화면에 있는지 요구 추적표를 한 줄씩 다시 읽는다.

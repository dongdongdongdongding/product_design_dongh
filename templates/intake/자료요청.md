# 화면 설계에 필요한 자료

1단계에서 사용자에게 보여 주는 목록입니다. **필수**가 하나라도 있으면 시작할 수 있습니다. 없는 것은 "없음"이라고 하면 대신할 방법으로 진행합니다.

| 구분 | 자료 | 형식 | 왜 필요한가 | 없으면 |
|---|---|---|---|---|
| 필수(둘 중 하나 이상) | 기획서 | PPT · PDF · HWP · 노션 · 이미지 | 화면 구성 · 흐름 · 항목의 근거 | 요구사항 정의서만으로 화면을 제안 |
| 필수(둘 중 하나 이상) | 요구사항 정의서 · 요청서 · RFP · 과업지시서 | XLSX · HWP · DOCX · PDF | 요구 ID · 범위 · 검수 기준 | 기획서에서 요구를 뽑아 "추출 요구"로 표시 |
| 권장 | 운영 중인 사이트 주소 | URL (로그인은 직접) | 실제 메뉴 · 옵션 · 디자인 값 | 디자인 질문으로 대신 |
| 권장 | 참고 화면설계서 · 디자인 가이드 | PDF · Figma · 이미지 | SB 형식 · 디자인 토큰 | 기본 SB 형식 사용 |
| 선택 | 기존 화면 캡처 · API 문서 · DB 정의 | 이미지 · 문서 | 기존 흐름 · 서버 경계(12장) | "배포 소스 확인 필요"로 표시 |
| 선택 | 일정 · 인력 조건 | 메모 | WBS 공수 기준 | 기본 가정(1인일 기준) |

## 요구사항 정의서를 받으면

- 원래 요구 ID(예: `SFR-001`, `REQ-12`)를 버리지 않고 요구 추적표(기능정의서 5.2)의 "원본" 칸에 그대로 씁니다.
- 한 요구가 여러 기능으로 나뉘면 `FAC-01~03`처럼 묶고, 여러 요구가 한 기능이면 줄을 나눠 같은 기능 ID를 씁니다.
- "필수 / 선택 / 제외" 구분이 있으면 그대로 범위 원칙에 반영합니다.

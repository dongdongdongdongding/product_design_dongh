## 1. 공통 화면 · 데이터 경계

### 1.1 화면 표시 원칙

- 신청자 연락처는 가운데 4자리를 가린다.
- 저장 성공은 오른쪽 위 알림으로 3초 보여 준다.

### 1.1a 화면 디자인 기준 (배포 사이트 테마)

- 기본 색 #2E9E6B, 카드 흰색 · 테두리 #F2F4F9 · 둥글기 4px, 버튼 높이 31px.

## 12. 입력값 · 서버 처리 · DB 명세

### 12.1 기능별 처리 위치

| 기능 | 입력 | 처리 위치 | 저장 · 조회 대상 | 운영 서버 · DB 영향 |
|---|---|---|---|---|
| DASH-01 | 없음 (읽기) | 서버 (기존 예약 조회) | reservation 수 | 읽기만 |
| FAC-02 | 시설 정보 | 서버 (기존 시설 API) | facility | 기존 테이블 쓰기 |
| BOOK-02 | 승인 · 반려 · 사유 | 서버 (기존 예약 API) | reservation.status · reject_reason | 상태 컬럼만 변경 |

### 12.2 입력 필드

| 화면 | 필드 | 키 | 타입 | 필수 | 검증 | 기본값 | 저장 위치 |
|---|---|---|---|---|---|---|---|
| F2 | 시설명 | name | 문자열 | 필수 | 앞뒤 공백 제거 후 1~50자, 중복 불가 | 없음 | facility.name |
| F2 | 유형 | type | 선택 | 필수 | 캠핑 · 체육 · 실내 · 공연 · 야외 | 캠핑 | facility.type |
| F2 | 수용 인원 | capacity | 정수 | 필수 | 1~999 | 없음 | facility.capacity |
| F2 | 이용 시간 | hours | 문자열 | 선택 | HH:MM ~ HH:MM | 09:00 ~ 18:00 | facility.hours |
| F2 | 운영 상태 | status | 선택 | 필수 | 운영 · 점검 중 | 운영 | facility.status |
| F2 | 안내 문구 | notice | 문자열 | 선택 | 500자 이하 | 없음 | facility.notice |
| F2 | 위치 | lat · lng | 좌표 | 필수 | 지도 클릭으로만, 공원 경계 안 | 없음 | facility.lat · lng |
| B2 | 반려 사유 | reason | 문자열 | 반려 시 필수 | 1~200자 | 없음 | reservation.reject_reason |

### 12.3 기존 서버 연동 경계

| 연동 | 흐름 | 경로 | 확인 상태 | 이번 처리 |
|---|---|---|---|---|
| 시설 API | F2 저장 | PUT /api/facilities/{id} | 확인 | 재사용 |
| 예약 API | B2 처리 | PATCH /api/reservations/{id} | 확인, 상태 확인 응답은 미확인 | 재사용 |

### 12.4 후속 실연동 API 제안

| 기능 | 메서드 · 경로 (제안) | 요청 | 응답 | 규칙 |
|---|---|---|---|---|
| BOOK-02 | PATCH /api/reservations/{id}/status | status, reason, version | 200 · 409 | version이 다르면 409 |

### 12.5 후속 DB 테이블 제안

| 테이블 (제안) | 주요 컬럼 | 키 · 관계 | 비고 |
|---|---|---|---|
| reservation (기존) | reject_reason 추가 | 기존 PK | 컬럼 추가만 |

### 12.6 서버 처리 규칙

- 예약 상태 변경은 저장 직전 현재 상태를 다시 읽어 비교한다.
- 반려 사유는 시민 알림 문구에 그대로 들어간다.

## 13. 지도 표현 명세

### 13.1 지도 기본 설정

| 항목 | 값 | 비고 |
|---|---|---|
| 지도 종류 | 카카오 기본 지도(ROADMAP) | 기존 SDK 재사용 |
| 초기 범위 | 공원 경계 전체 | 경계 GeoJSON 기준 |
| 확대 범위 | 레벨 2~6 | 공원 밖으로 이동 제한 |

### 13.2 지도 기호

| 객체 | 카카오 객체 | 모양 | 색 · 선 | 쌓임 순서 | 라벨 · 상호작용 |
|---|---|---|---|---|---|
| 시설 (운영) | Marker(MarkerImage) | 물방울 핀 22×30 px | #2E9E6B | 5 | 클릭 시 시설 수정 |
| 시설 (점검 중) | Marker(MarkerImage) | 물방울 핀 22×30 px | #9AA3AF | 4 | 클릭 시 시설 수정 |
| 선택 위치 | Marker(MarkerImage) | 물방울 핀 22×30 px | #E8554E | 6 | 드래그로 이동 |
| 공원 경계 | Polygon | 면 | #D9EBCF · 선 #2E9E6B 1px | 1 | 없음 |

### 13.3 화면별 지도 구성

| 화면 | 기본 표시 | 토글 | 초기 범위 | 클릭 동작 | 범례 | 비었을 때 · 실패 |
|---|---|---|---|---|---|---|
| D1 대시보드 | 시설 전체 | 없음 | 공원 경계 | 없음 | 운영 · 점검 중 | SDK 실패 시 안내, 카드 유지 |
| F1 시설 목록 · 지도 | 시설 전체 | 없음 | 공원 경계 | 시설 → 수정 | 운영 · 점검 중 | SDK 실패 시 목록만 |
| F2 시설 등록 · 위치 선택 | 시설 · 선택 위치 | 없음 | 공원 경계 | 지도 → 위치 선택 | 없음 | SDK 실패 시 저장 차단 |

### 13.4 그리기 규칙

- 공원 밖 클릭은 위치로 받지 않는다.
- 선택 위치 핀은 다른 핀보다 위에 그린다.

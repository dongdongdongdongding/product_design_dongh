screen-spec-kit 스킬을 열고 "0. 시작"부터 따른다.

- `$ARGUMENTS`에 폴더가 있으면 그곳을, 없으면 현재 폴더를 작업 폴더로 쓴다. `spec-kit/progress.md`가 있으면 이어서 진행한다.
- `자동`이 있으면 자동 모드(확인 지점에서 멈추지 않고 기본값으로 진행, 마지막에 가정 목록 보고).
- 첫 메시지 형식과 작업 폴더 규칙은 스킬의 "작업 폴더" · "0. 시작"을 따른다.

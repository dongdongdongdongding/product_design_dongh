screen-spec-kit 스킬을 열고 "첫 응답"부터 따른다.

- `$ARGUMENTS`에 폴더가 있으면 그곳을, 없으면 현재 폴더를 작업 폴더로 쓴다. `spec-kit/progress.md`가 있으면 이어서 진행한다.
- `자동`이 있으면 결정이 필요한 곳(분해 확인 · 시안 선택 · 범위 증가)도 기본안으로 진행하고 마지막에 가정 목록을 한 번에 보고한다.
- 인자 뒤에 아이디어 문장이 붙어 있으면 그것을 자료로 보고 바로 기획 분해부터 시작한다.
